# studyflow — UI/UX case study

Slide-deck case study for [studyflow](https://coolgithub1.github.io/School-Schedule-Builder-App/), a mobile-first semester schedule builder.

- Live deck: https://coolgithub1.github.io/studyflow-case-study/
- PDF: [studyflow-case-study.pdf](studyflow-case-study.pdf)

`tools/` holds the Playwright scripts that capture the app screenshots (`capture.mjs`) and build `slides.html` + the PDF (`build.mjs`). Run `npm install` in `tools/` first.

Deployed to GitHub Pages by `.github/workflows/deploy-pages.yml` on every push to `main`.
